## 문제 원인

**nginx 설정** (`infrastructure/nginx/nginx.conf:131-142`):
```nginx
location /common/ {
    if ($http_accept !~* "application/json") {
        rewrite ^(.*)$ /api-redirect$1 last;  # → 프론트엔드로 보냄
    }
    proxy_pass http://core_service/common/;
    ...
}
```

nginx가 **`Accept: application/json` 헤더가 없는 요청**을 API 서버가 아닌 **프론트엔드로 리디렉션**합니다.

`useAppSettings.tsx`에서 `Accept` 헤더가 누락되어 있어서:
- **로컬**: nginx 없이 직접 `http://localhost:3011/common/...` 호출 → 정상 동작
- **서버**: nginx가 요청을 프론트엔드로 리디렉션 → 설정 로드 실패

## 해결

`Accept: application/json` 헤더를 추가했습니다:

```typescript
headers: {
  "Content-Type": "application/json",
  "Accept": "application/json",  // ← 추가
},
```

서버에 배포 후 앱 설정이 정상적으로 반영되는지 확인해주세요.
