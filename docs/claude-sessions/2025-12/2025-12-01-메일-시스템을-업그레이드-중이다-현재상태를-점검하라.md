## Git 강제 Merge 가이드

히스토리가 재작성되어 충돌이 발생한 경우, 아래 방법 중 선택하세요:

---

### 방법 1: 현재 브랜치(15-mail)를 main에 강제 반영

현재 브랜치 내용을 main으로 완전히 대체하는 방법:

```bash
# 1. 먼저 로컬 변경사항 커밋
git add -A && git commit -m "feat: Mail system v2 with attachments"

# 2. main 브랜치로 이동
git checkout main

# 3. 15-mail 브랜치 내용으로 완전히 대체
git reset --hard 15-mail

# 4. 원격 main에 강제 push (주의!)
git push origin main --force
```

---

### 방법 2: main을 현재 브랜치에 강제 병합 (현재 내용 우선)

```bash
# "ours" 전략 - 충돌 시 현재 브랜치(15-mail) 내용 우선
git merge -X ours origin/main --allow-unrelated-histories
```

---

### 방법 3: GitHub PR에서 강제 Merge

GitHub UI에서:
1. PR 페이지 하단 **"Merge pull request"** 드롭다운 클릭
2. **"Squash and merge"** 또는 **"Rebase and merge"** 선택
3. 그래도 안 되면 CLI로:

```bash
# main을 15-mail 기준으로 강제 업데이트
git checkout main
git reset --hard origin/15-mail
git push origin main --force
```

3. **모든 브랜치를 현재 히스토리 기준으로 재정렬**
