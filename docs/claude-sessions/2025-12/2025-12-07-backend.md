## 문제 분석

`userRoleMapping.js`에서 admin 권한 체크를 `req.user.role !== 'admin'`으로 하고 있습니다. 이는 **users 테이블의 `role` 컬럼**을 사용합니다.

그러나 시스템은 **RBAC(Role-Based Access Control)**을 구현하여 `user_role_mappings` 테이블과 `role_program_mappings` 테이블을 통해 권한을 관리하고 있습니다. 

`permissionMiddleware.js`에는 이미 RBAC 기반의 권한 체크 함수들(`getUserProgramPermissions`, `requirePermission` 등)이 있지만, `userRoleMapping.js`에서는 이를 사용하지 않고 레거시 방식으로 `req.user.role`을 직접 체크하고 있습니다.

**해결책:** `userRoleMapping.js`에서 admin 권한 체크를 RBAC 기반으로 변경하거나, 최소한 users 테이블의 role이 'admin'인 경우 뿐만 아니라 user_role_mappings를 통해 admin 역할을 가진 사용자도 허용해야 합니다.

가장 간단한 해결책은 `requirePermission` 또는 admin role 체크를 RBAC와 호환되도록 수정하는 것입니다.
