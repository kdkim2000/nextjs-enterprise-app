## 4. 기능 요구사항

### 4.1 인증 시스템 (Authentication)

#### 4.1.1 로그인
```
- 이메일/비밀번호 로그인
- JWT 기반 인증 (Access Token + Refresh Token)
- Access Token: 15분 만료
- Refresh Token: 7일 만료 (HttpOnly Cookie 또는 localStorage)
- 자동 토큰 갱신 (401 응답 시)
- 로그인 실패 횟수 제한 (5회 후 계정 잠금)
```

#### 4.1.2 MFA (다중 인증)
```
- TOTP 기반 2단계 인증
- QR 코드 등록
- 백업 코드 발급
- MFA 활성화/비활성화
```

#### 4.1.3 SSO (Single Sign-On)
```
- OAuth 2.0 / OIDC 지원
- 외부 IdP 연동 (선택적)
```

#### 4.1.4 세션 관리
```
- 자동 로그아웃 경고 (만료 5분 전)
- 세션 연장 옵션
- 강제 로그아웃 (관리자)
```
