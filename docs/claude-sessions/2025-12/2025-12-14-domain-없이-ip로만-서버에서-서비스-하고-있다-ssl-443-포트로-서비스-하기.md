## IP 주소로 SSL 443 서비스 방법

### 1. 자체 서명 인증서 생성 (Self-signed Certificate)

도메인 없이 IP로 SSL을 사용하려면 자체 서명 인증서가 가장 현실적인 방법입니다.

```bash
# 인증서 저장 디렉토리 생성
mkdir -p /etc/ssl/private

# 자체 서명 인증서 생성 (IP 주소 사용)
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/ssl/private/server.key \
  -out /etc/ssl/certs/server.crt \
  -subj "/CN=YOUR_SERVER_IP" \
  -addext "subjectAltName=IP:YOUR_SERVER_IP"
```

`YOUR_SERVER_IP`를 실제 서버 IP 주소로 변경하세요.

---

### 2. 방법 A: Nginx 리버스 프록시 (권장)

```nginx
# /etc/nginx/sites-available/default

server {
    listen 80;
    server_name _;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name _;

    ssl_certificate /etc/ssl/certs/server.crt;
    ssl_certificate_key /etc/ssl/private/server.key;
    
    # SSL 설정
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256;
    ssl_prefer_server_ciphers on;

    location / {
        proxy_pass http://localhost:3000;  # Next.js 앱 포트
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

```bash
# Nginx 설정 테스트 및 재시작
sudo nginx -t
sudo systemctl restart nginx
```

### 3. 방법 B: Node.js 직접 HTTPS 설정

`server.js` 파일 생성:

```javascript
const https = require('https');
const fs = require('fs');
const next = require('next');

const dev = process.env.NODE_ENV !== 'production';
const app = next({ dev });
const handle = app.getRequestHandler();

const httpsOptions = {
  key: fs.readFileSync('/etc/ssl/private/server.key'),
  cert: fs.readFileSync('/etc/ssl/certs/server.crt')
};

app.prepare().then(() => {
  https.createServer(httpsOptions, (req, res) => {
    handle(req, res);
  }).listen(443, () => {
    console.log('> HTTPS Server running on https://YOUR_SERVER_IP:443');
  });
});
```

## 방안 3: 공통 데이터 뷰 컴포넌트 (추천 조합)

**ResponsiveDataView 패턴**

```typescript
// ResponsiveDataView.tsx
interface ResponsiveDataViewProps<T> {
  data: T[];
  loading?: boolean;
  // 데스크톱 설정
  columns: GridColDef[];
  // 모바일 설정
  mobileCardRenderer: (item: T) => React.ReactNode;
  mobileListActions?: (item: T) => React.ReactNode;
  // 공통
  onItemClick?: (item: T) => void;
  onSearch?: (query: string) => void;
}

export function ResponsiveDataView<T>({
  data,
  columns,
  mobileCardRenderer,
  ...props
}: ResponsiveDataViewProps<T>) {
  const { isMobileLayout } = useMobile();

  if (isMobileLayout) {
    return (
      <MobileCardList
        data={data}
        renderCard={mobileCardRenderer}
        {...props}
      />
    );
  }

  return (
    <DataGrid
      rows={data}
      columns={columns}
      {...props}
    />
  );
}
```

**사용 예시:**

```typescript
<ResponsiveDataView
  data={users}
  columns={userColumns}
  mobileCardRenderer={(user) => (
    <UserCard user={user} />
  )}
  onItemClick={handleUserClick}
/>
```
