## 오류 분석

**원인**: HTML 규칙 위반 - `<p>` 태그 안에 `<div>` 태그를 넣을 수 없음

### 문제 코드 흐름

```
ListItemText secondary prop
  → Typography (variant="body2") → <p> 태그로 렌더링
    → Box → <div> 태그로 렌더링  ❌ 잘못됨
      → Chip → <div> 태그로 렌더링  ❌ 잘못됨
```

### 문제 위치 (page.tsx:393-398)

```tsx
<ListItemText
  primary={...}
  secondary={
    <Box sx={{ display: 'flex', ... }}>  // <-- Box는 <div>로 렌더링
      <Chip ... />                        // <-- Chip도 <div>로 렌더링
    </Box>
  }
/>
```
