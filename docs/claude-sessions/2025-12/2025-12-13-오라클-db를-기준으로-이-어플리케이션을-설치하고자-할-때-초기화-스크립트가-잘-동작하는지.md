## 4. 문제 해결

### 오류: ORA-12514 - TNS:listener does not currently know of service

**원인:** 서비스 이름이 잘못됨

**해결:**
```bash
# 서비스 이름 확인
lsnrctl status

# 올바른 서비스 이름으로 연결
export DB_CONNECT_STRING="localhost:1521/ORCL"  # 또는 XEPDB1
```

### 오류: ORA-01017 - invalid username/password

**원인:** 사용자/비밀번호 불일치

**해결:**
```sql
-- SYS로 비밀번호 재설정
ALTER USER corenext IDENTIFIED BY "<REDACTED>";
```

### 오류: ORA-00942 - table or view does not exist

**원인:** 스키마가 적용되지 않음

**해결:** Step 2 스키마 적용 다시 실행

### 오류: NJS-045 - cannot load Oracle Client library

**원인:** Oracle Instant Client 미설치 또는 경로 설정 안됨

**해결:**
```bash
# Windows - 환경변수에 Instant Client 경로 추가
set PATH=C:\oracle\instantclient_19_8;%PATH%

# Linux - LD_LIBRARY_PATH 설정
export LD_LIBRARY_PATH=/opt/oracle/instantclient_19_8:$LD_LIBRARY_PATH
```

|------|------------------------------|
| `original-schema-oracle.sql` | `"order"` (큰따옴표로 예약어 처리) |
| `load-oracle-data.js` | `TYPE_ORDER`로 변환 시도 |

PostgreSQL과 Oracle의 차이점을 설명하겠습니다.

## PostgreSQL vs Oracle 비교

| 문제 | Oracle | PostgreSQL |
|------|--------|------------|
| **문자열 리터럴 길이** | 4000바이트 제한 | 제한 없음 (1GB까지) |
| **CLOB 처리** | 바인드 변수 필요 | TEXT 타입으로 직접 처리 |
| **예약어** | ORDER, TYPE, LEVEL 등 엄격 | 더 관대함 |
| **데이터 로드** | INSERT 또는 SQL*Loader | COPY 명령어 (매우 빠름) |

## PostgreSQL이 문제없는 이유

### 1. COPY 명령어 사용

PostgreSQL의 `master-data.sql` 파일을 보면:

```sql
COPY public.app_settings (key, value, ...) FROM stdin;
데이터1	데이터2	...
데이터1	데이터2	...
\.
```

이 형식은 `psql` 클라이언트가 직접 처리하므로:
- SQL 파싱 단계를 거치지 않음
- 문자열 길이 제한 없음
- 매우 빠른 로드 속도

### 2. 예약어 처리

```sql
-- PostgreSQL: 큰따옴표 없이도 동작
CREATE TABLE test (
    order INTEGER,      -- 경고만 발생, 동작함
    "order" INTEGER     -- 권장 방식
);

-- Oracle: 반드시 큰따옴표 필요
CREATE TABLE test (
    "order" NUMBER(10)  -- 필수
);
```

## 결론

**PostgreSQL:**
```bash
# 한 줄로 끝
psql -f master-data.sql
```
- `COPY FROM stdin` 명령어가 데이터를 직접 스트리밍
- SQL 파싱 없이 바이너리 처리
- 16MB 파일도 수초 내 로드

**Oracle:**
```bash
# Node.js 스크립트 필요
node load-oracle-data.js
```
- COPY 명령어 미지원
- PostgreSQL 덤프 → 파싱 → INSERT 변환 필요
- 바인드 변수로 CLOB 제한 우회 필요

## Oracle에서 동일한 성능을 원한다면

Oracle에서 대용량 데이터를 빠르게 로드하려면 **SQL*Loader**를 사용해야 합니다:

```bash
# 1. 데이터를 CSV로 변환
# 2. 컨트롤 파일 작성
# 3. SQL*Loader 실행
```
